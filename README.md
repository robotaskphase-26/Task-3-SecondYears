---

## 🧠 Task 1: Linear Regression  

### 🎯 Objective  

Predict **miles per gallon** using Linear Regression.

You are given a dataset **auto-mpg.csv** which contains information about various automobiles, including engine displacement, horsepower, vehicle weight, acceleration, and model year

Your goal is to build a Linear Regression model from scratch using NumPy to predict the miles per gallon (mpg) of automobiles and visualize the regression results using Matplotlib

---

## 🧠 Task 2: Logistic Regression  

### 🎯 Objective  

Predict whether **a person earns >50K or <=50K annually** using Logistic Regression.

You are provided with the dataset adult.csv, which contains census including age, education, occupation, and other socioeconomic
indicators. 

Your task is to implement Logistic Regression from scratch using NumPy to predict whether a person earns >50K or <=50K annually. You will preprocess the data, train your model, visualize results, and evaluate its performance.
